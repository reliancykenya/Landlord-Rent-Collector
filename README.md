# 🏠 Landlord Rent Collector

**Landlord Rent Collector** is a native Android application that helps independent landlords create, send, and track rent invoices and payments. The app replaces spreadsheets and manual paperwork with a simple offline solution built with Kotlin.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Android](https://img.shields.io/badge/platform-Android-green)

---

## ✨ Features

- 📍 Manage multiple properties with addresses and unit details
- 👥 Store tenant information and link them to properties
- 🧾 Generate professional rent invoices with due dates and optional late fees
- 📤 Send invoices via email or messaging apps
- 💰 Record payments with date and method and automatically issue receipts
- 📊 Dashboard showing upcoming due dates, outstanding payments, and recent income
- 📈 Generate income reports (PDF/CSV)
- ⏰ Local reminders for upcoming and past-due rent
- 🔒 All data stored securely on device using Room (SQLite)

---

## 🛠️ Technology Stack

- Kotlin & Jetpack Compose
- Room for local database storage
- Material Design 3 for UI components
- Fully offline first architecture

## 🚀 Getting Started

### Prerequisites
- [Android Studio](https://developer.android.com/studio) with the latest Android SDK
- Kotlin 1.9+
- Android device or emulator (API 23+)

### Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/yourusername/landlord-rent-collector.git
   cd Landlord-Rent-Collector
   ```
2. Open the project in Android Studio.
3. Build and run on an Android device or emulator.
